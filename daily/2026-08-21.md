# Crear nueva version de engine en SageMaker sin merge

## Objetivo
Permitir la creacion de una nueva version del engine desde una feature branch, sin necesidad de hacer merge.

## Requisito
Crear un archivo `ci.yml` en la raiz del repositorio con este contenido:

```yaml
featurebranch_sgpipeline: true
```

## Pasos
1. Verifica que el archivo `ci.yml` exista en la raiz del repo.
2. Asegura que la clave `featurebranch_sgpipeline` tenga valor booleano `true`.
3. Crea o actualiza la PR segun el flujo habitual del equipo.
4. Desde Sandbox Manager/SageMaker, ejecuta la creacion de version del engine.

## Nota
Si el pipeline no toma el cambio, revisa que el artefacto/branch desplegado sea el actualizado y no una version antigua del repositorio.
