##  Conceptos Clave

### Rutas Absolutas (Obligatorias)
```
✅ CORRECTO:  /Users/t022458/Documents/BBVA_vault/...
❌ INCORRECTO: ~/Documents/BBVA_vault/...
```

### Patrón de Actualización
```
1. LECTURA: Inicio de sesión
   - INSTRUCCIONES_BASE.md
   - Proyecto ESTADO.md
   - Proyecto CAMBIOS_RECIENTES.md

2. TRABAJO: Implementar cambios

3. ESCRITURA: Cierre de sesión
   - Editar CAMBIOS_RECIENTES.md
   - Editar ESTADO.md
   - Crear/editar daily/YYYY-MM-DD.md
```

### Capacidades de Copilot
- ✅ **Lectura:** Todos los archivos .md
- ✅ **Escritura:** CAMBIOS_RECIENTES, ESTADO, daily notes
- ✅ **Creación:** Nuevas documentación según necesidad
- ❌ **Automático:** NO sincroniza automáticamente
