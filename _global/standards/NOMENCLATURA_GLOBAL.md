# Nomenclatura Global

## Carpetas
- `_global/` para contenido comun.
- `proyectos/<nombre>/` para contenido local.

## Archivos
- Usa nombres descriptivos con mayusculas/guion bajo si ya es la convencion del vault.
- Mantener consistencia dentro del mismo modulo.

- Ver norma completa en [[_global/standards/WIKILINKS_CONVENCION]].
