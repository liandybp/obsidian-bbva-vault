# 🚀 Quick Start - Guía de 5 Minutos

**Para empezar AHORA mismo tu vault Obsidian**

---

## 📱 Paso 1: Instalar Obsidian (2 min)

```bash
# Opción A: Web (más rápido ahora)
# Visita: https://obsidian.md/download

# Opción B: Homebrew (si tienes brew)
brew install obsidian
```

---

## 📂 Paso 2: Abrir tu Vault (1 min)

1. Abre **Obsidian** 
2. Click en **"Open folder as vault"**
3. Navega a: `~/Documents/kpfm-obsidian-vault/`
4. Click en **"Open"**

✅ Listo. Verás carpetas en panel izquierdo.

---

## 📖 Paso 3: Lee (2 min) - EN ESTE ORDEN

**Antes de cada sesión de trabajo:**

```
1️⃣ README.md (sí, este archivo)
   ↓
2️⃣ contexto/CONTEXTO_ACTUAL.md (estado actual)
   ↓
3️⃣ contexto/COPILOT_INSTRUCTIONS.md (reglas a respetar)
```

**Máximo: 3 minutos. Eso es suficiente.**

---

## 🔗 Paso 4: Navegar (Shortcuts)

```
Cmd+O          → Buscar archivo ("search" o "context")
Cmd+P          → Command palette
Cmd+Shift+F    → Buscar dentro de texto
Cmd+Click      → Seguir link interno
```

---

## ✏️ Paso 5: Actualizar después de trabajar (2 min)

Después de una sesión productiva:

1. Abre `contexto/CAMBIOS_RECIENTES.md`
2. Agrega una línea con qué hiciste:
   ```markdown
   ## [Fecha] - [Feature Name]
   - ✅ Implementé [qué]
   - ✅ Tests: [cuántos]
   ```
3. Guarda (Cmd+S)

**Eso es todo.**

## ❓ Preguntas Comunes

**P: ¿Cómo sabe Copilot del contexto?**
R: Le muestras este vault cuando le das instrucciones

**P: ¿Puedo editar archivos?**
R: Sí, cualquiera menos archivos de referencia (actualiza notas para cambios)

**P: ¿Qué si necesito ayuda con Spark?**
R: Ve a `referencias/SPARK_FUNCTIONS.md` y busca función
